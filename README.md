# Sitio web estático (español) — Resoluciones Industriales

Este paquete contiene un **sitio web estático** listo para desplegar en GitHub Pages, Cloudflare Pages o Netlify. 
Es una plantilla básica: textos en español, imágenes desde Unsplash (placeholders) y un formulario que utiliza **Formspree** (requiere registro para obtener el endpoint).

Archivos incluidos:
- index.html
- about.html
- products.html
- contact.html
- css/styles.css
- CNAME (archivo con tu dominio, reemplazar antes de subir si vas a usar GitHub Pages)
- DEPLOY_INSTRUCTIONS.md (instrucciones paso a paso)

**IMPORTANTE legal y de contenido:** no copies textos ni imágenes de terceros sin permiso. Esta plantilla usa textos originales y fotos libres (Unsplash). Reemplaza la información de contacto, logos e imágenes por tus propios recursos antes de publicar.
